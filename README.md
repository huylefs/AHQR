# AHQR
# Introduction <a name="introduction"></a>
This is the end-term project at Samsung R&D Vietnam Internship. In this project, we created an Android QR Application which can be used to scan or generate QR code based on several basic information: Address, Phone number. You can also send text, send email or make phone call by scanning our generated QR code.
